## Mein Hauptprojekt

Projektname: Bewerbungstracker

Ziel:
Ein kleines Tool, mit dem ich Bewerbungen verwalten kann.

Warum dieses Projekt sinnvoll ist:
Es hilft mir direkt bei meiner Jobsuche und zeigt gleichzeitig, dass ich ein praktisches Problem mit Software lösen kann.

Technologie:
- Sprache: C# o.Ä. OOP-Sprache
- Versionierung: Git
- Plattform: Lokal auf meinem Rechner
- Ausgabe: Konsole, Datei oder später einfache GUI

Mindestfunktionen:
- Firma hinzufügen
- Stelle hinzufügen
- Status speichern
- Datum speichern
- Notizen speichern
- Bewerbungen anzeigen
- Daten in Datei speichern

Optionale spätere Funktionen:
- CSV Export
- Suche/Filter
- einfache GUI
- Erinnerungen
- Statistik
