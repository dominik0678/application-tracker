# Application Tracker

Ein kleines lokales Tool zur Verwaltung von Bewerbungen.

Das Projekt dient dazu, Bewerbungen übersichtlich zu erfassen und den aktuellen Status jeder Bewerbung nachzuverfolgen. Gleichzeitig ist es ein praktisches Lernprojekt, um saubere Datenstrukturen, Datei-Speicherung und einfache Benutzerinteraktion umzusetzen.

## Ziel

Viele Bewerbungen werden schnell unübersichtlich. Dieses Tool soll helfen, wichtige Informationen zu jeder Bewerbung an einem Ort zu speichern.

Gespeichert werden zum Beispiel:

- Firma
- Stelle
- Ort
- Bewerbungsstatus
- Datum
- Kontaktperson
- Link zur Stelle
- Notizen

## Geplante Funktionen

- Bewerbung hinzufügen
- Bewerbungen anzeigen
- Bewerbungsstatus ändern
- Notizen ergänzen
- Daten lokal speichern und laden
- CSV-Export
- einfache Statistik über Bewerbungsstatus

## Status

In Entwicklung.

Aktuell wird zuerst eine einfache Konsolen-Version umgesetzt. Spätere Erweiterungen wie Filter, Suche oder eine einfache grafische Oberfläche sind möglich.

## Technologien

- C# oder Ähnliche OOP-Sprachen
- JSON oder CSV zur lokalen Speicherung
- Git zur Versionsverwaltung

## Warum dieses Projekt?

Das Projekt löst ein echtes Problem aus meinem aktuellen Alltag: den Überblick über Bewerbungen behalten.

Zusätzlich nutze ich es, um praktische Softwareentwicklung sauber zu üben:

- strukturierter Code
- einfache Datenmodelle
- Datei-Ein- und Ausgabe
- nachvollziehbare Projektstruktur
- saubere Dokumentation
